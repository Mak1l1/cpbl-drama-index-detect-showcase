# CPBL Drama Index Detect ⚾️📈

這是一個基於 **YOLOv8** 的棒球轉播分析專案，旨在透過偵測比賽畫面中的 UI 元素（如計分板、壘包狀態）來計算比賽的「張力指數 (Drama Index)」


## 📖 專案介紹

本專案運用深度學習物體偵測技術，自動分析棒球轉播畫面中的關鍵元素，並根據比賽情勢計算一個量化的「張力指數」。此指數可用於：
- 分析比賽的精彩程度
- 識別轉折點和高潮時刻
- 自動通知使用者收看高張力直播畫面

## 🛠 技術棧

- **環境管理**: [uv](https://docs.astral.uv/)
- **模型**: YOLOv8 (Ultralytics)
- **影像處理**: OpenCV
- **語言**: Python

## 🚀 核心功能

- 自動偵測棒球轉播畫面中的 UI 元素
- 追蹤壘包狀態與計分板資訊
- 計算並可視化張力指數
